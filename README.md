A PyTorch implementation of a custom 6-layer deep Convolutional Neural Network (CNN) for 10-class image classification on the CIFAR-10 benchmark dataset. The architecture utilizes progressive spatial downsampling, Batch Normalization, layered Dropout regularization, and a Cosine Annealing learning rate schedule to achieve ~82.4% validation accuracy with minimal overfitting.
#Key FeaturesCustom 6-Layer Architecture: Engineered with dual convolution blocks ($3\times3$ kernels) and explicit feature channel expansion ($3 \rightarrow 32 \rightarrow 64 \rightarrow 128$).Regularization & Stability: Integrated Batch Normalization after each convolutional layer and progressive Dropout ($0.2 \rightarrow 0.5$) across depth blocks to maintain small generalization gaps ($<6.1\%$).Data Augmentation Pipeline: Real-time training augmentations including random crops with 4-pixel padding and horizontal flipping combined with channel-wise RGB standardization ($\mu, \sigma$).Optimization Strategy: Stochastic Gradient Descent (SGD) with $0.9$ momentum, weight decay ($5\times 10^{-4}$), and dynamic Cosine Annealing learning rate decay.Device Agnostic Execution: Automatic hardware detection supporting NVIDIA CUDA, Apple Silicon MPS, and CPU fallback modes.
#Per-Class Performance InsightsStrongest Categories ($>88\%$ Accuracy): Distinct macro-features allow high performance on Automobile, Ship, Truck, and Frog.Fine-Grained Challenges: Primary confusion occurs among animal categories with overlapping background and structural features (e.g., Cat vs. Dog, Bird vs. Deer).
